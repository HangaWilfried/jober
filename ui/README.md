# Jober

Assistant personnel de recherche d’emploi. L’application démarre par une interface de découverte d’offres qui met en avant le matching, les compétences et l’état de sauvegarde.

## Démarrer

```bash
pnpm install
pnpm dev
```

Les offres affichées sont des données de démonstration. Aucun compte, CV, service IA ou site d’emploi n’est encore connecté.

## État actuel

- Interface responsive de découverte des offres.
- Recherche textuelle, filtres de pertinence et d’actualité.
- Sauvegarde d’offres en mémoire pendant la session.
- Création de recherches depuis une boîte de dialogue.
- Configuration React, TypeScript strict, Vite, Tailwind, ESLint, Prettier et Vitest.

Prochaine étape fonctionnelle : définir le profil et les préférences, puis remplacer les données de démonstration par un contrat API et une première source d’offres autorisée.
